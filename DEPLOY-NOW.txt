WHY LOCAL WORKS BUT LIVE DOESN'T:
  Live uses Cloudflare Rocket Loader which DEFERS inline scripts.
  Without data-cfasync="false", window.__CHECKOUT__ loads AFTER Alpine starts
  → cart empty, subtotal $0, Order Summary (0).

  Latest fix adds data-cfasync="false" + backup config in checkout body.

--------------------------------------------------------------------------------

  $env:FTP_PASSWORD = "your-ftp-password"
